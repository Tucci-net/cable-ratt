## Overview

Cable Ratt is an AV dashboard that would help AV programmers understand systems and signal flow better via product notation and documentation. Cable ratt acts as a tool to commune between such.  Built for teams that need multi-tenant access, role-based permissions, and enterprise-grade reliability out of the box.

## Tech Stack

| Layer | Choice |
|---|---|
| Framework | Next.js (App Router) |
| Language | TypeScript (strict) |
| Styling | Tailwind CSS + shadcn/ui |
| Data fetching | TanStack Query |
| Validation | Zod |
| Database | [Postgres via Neon / Supabase / Vercel Postgres] |
| ORM | [Drizzle / Prisma] |
| Auth | [Auth.js / Clerk / WorkOS] |
| Charts | Tremor / Recharts |
| Hosting | Vercel |
| Testing | Vitest + Playwright |

## Getting Started

### Prerequisites

- Node.js ≥ 20
- pnpm ≥ 11

### Installation

```bash
git clone https://github.com/your-org/cable-ratt.git
cd cable-ratt
pnpm install
```

### Development

```bash
pnpm dev
```

App runs at `http://localhost:3000`.

### Build

```bash
pnpm build
pnpm start
```

## Environment Variables

Create a `.env.local` in the project root:

```bash
# Database
DATABASE_URL=

# Auth
AUTH_SECRET=
AUTH_URL=

# Third-party services
NEXT_PUBLIC_APP_URL=
```

See `.env.example` for the full list.

## Project Structure

```
/app                    → App Router routes (route groups: (auth), (dashboard), (marketing))
/components
  /ui                   → base UI primitives
  /features             → feature-specific composed components
/lib
  /api                  → typed API client / fetchers
  /auth                 → session/auth helpers
  /db                   → ORM client, queries
  /utils
/hooks
/types                  → shared TS types, zod schemas
/config                 → env, feature flags, constants
/tests
```

## Scripts

| Command | Description |

| `pnpm dev` | Start local dev server |
| `pnpm build` | Production build |
| `pnpm lint` | Run ESLint |
| `pnpm typecheck` | Run TypeScript compiler check |
| `pnpm test` | Run unit tests (Vitest) |
| `pnpm test:e2e` | Run end-to-end tests (Playwright) |

## Deployment

This project deploys to [Vercel](https://vercel.com). Every PR gets a preview deployment; merges to `main` deploy to production automatically.

| Environment | Branch | URL |
|---|---|---|
| Production | `main` | [cableratt.app](https://cableratt.app) |
| Staging | `staging` | — |
| Preview | any PR | auto-generated by Vercel |

## Contributing

1. Create a branch off `main`: `git checkout -b feature/your-feature`
2. Make your changes, following the existing lint/type conventions
3. Run `pnpm lint && pnpm typecheck && pnpm test` before opening a PR
4. Open a PR against `main` — preview deploy will be attached automatically

See [CONTRIBUTING.md](./CONTRIBUTING.md) for more detail.
